# 6. First scientific design rule: three cadence layers

Do not optimize for a single "latest value".

Maintain three independent information layers.

## Layer A — Fast observational layer

Purpose:
Situational awareness.

Typical cadence:
Daily to weekly.

Candidate examples requiring live verification:

- NOAA/NCEI Daily OISST.
- NOAA/CPC weekly Niño-region SST indices.
- IMARPE daily oceanographic bulletin.
- IMARPE weekly coastal SST bulletin.
- PMEL TAO/TRITON daily observations.
- Higher-frequency validated wind or ocean products.

These may update dashboard observations.

They do not independently create an official ENSO declaration.

## Layer B — Operational climate-index layer

Purpose:
Climate monitoring using defined methodologies.

Examples:

- ICEN / ICEN temporal.
- RONI.
- SOI and running SOI.
- CPC trade-wind indices.
- D20 or an explicitly defined thermocline metric.

Use the source's real calculation, cadence, climatology, and revision policy.

Do not fabricate higher-frequency versions merely because faster raw data are
available.

## Layer C — Official-authority layer

Purpose:
Display what the authority actually publishes.

Examples:

- ENFEN official coastal status.
- NOAA/CPC ENSO Alert System status.

Store:

- authority
- publication date
- valid period
- exact classification
- source
- retrieval evidence

The official state may remain unchanged while Layer A updates daily.

# 12. Retry and perseverance policy

"Robust and persevering" means bounded, adaptive recovery.

It does not mean retry forever.

For idempotent GET requests:

- Use a finite attempt budget.
- Exponential backoff with jitter.
- Honor Retry-After within total runtime budget.
- Retry transient network errors.
- Retry appropriate 429 and 5xx responses.
- Do not endlessly retry deterministic 4xx errors.
- Do not retry schema incompatibility without a changed source or parser
  hypothesis.

After the budget:

1. Evaluate a scientifically compatible fallback.
2. Preserve last-known-valid historical data.
3. Suppress stale current-state claims.
4. Record source failure.
5. Alert.
6. Continue independent sources when safe.
